# Prompt: add screens to a generated app

Paste into an agent opened on the generated app (not the builder).

```text
Read AGENTS.md and docs/SCREENS.md. Add these screens with mock data first:
<route - purpose - data shown - actions, one per line>
Use the app's existing UI kit and theme tokens, include loading/empty/error states and accessible
labels, add a unit test per screen, run `bash start.sh verify`, and view each screen on the web.
```
