# Features

This app was generated by Mobile Starter App Builder from its Expo template. The template ships these
features; each can be switched off here, or removed and added back with the builder.

| ID              | Feature                                                                                                                | Switch here          |
| --------------- | ---------------------------------------------------------------------------------------------------------------------- | -------------------- |
| `auth`          | Supabase sign-in (Apple, Google), secure session storage, sign-out, account deletion, backend schema and edge function | yes                  |
| `payments`      | RevenueCat subscriptions: entitlement, paywall route and gate, Manage subscription                                     | yes                  |
| `analytics`     | PostHog: screen tracking, typed events, identify/reset, feature flags, opt-out switch in Settings                      | yes                  |
| `notifications` | Local trial-reminder notification and deep links from tapped notifications                                             | yes                  |
| `local-db`      | Expo SQLite with Drizzle ORM behind the home repository                                                                | no (remove/add only) |
| `device-kit`    | Preinstalled camera, image and document pickers, clipboard, sharing, network state                                     | no (remove/add only) |
| `ota-updates`   | Over-the-air JavaScript updates with `expo-updates`                                                                    | no (remove/add only) |
| `funnel`        | Optional: the upstream 28-step onboarding funnel and full custom paywall                                               | add/remove only      |

## Switch a feature off or on

```bash
bash start.sh feature list
bash start.sh feature off payments
bash start.sh feature on payments
```

This edits `src/constants/features.ts`. Code and native packages stay installed; a feature that is off
never starts its service, even when its keys are in `.env`, and its screens and gates step aside. A
service is also off while its public keys are missing from `.env`.

## Remove or add a feature

Removing deletes the feature's code and native packages so the app binary no longer carries them. Run
it from the builder repository, passing this app's folder:

```bash
bash start.sh expo feature status /path/to/this-app
bash start.sh expo feature remove payments /path/to/this-app
bash start.sh expo feature add payments /path/to/this-app
bash start.sh expo feature add funnel /path/to/this-app
```

Removed files are kept in `.mobile-builder/removed/` and the record in `.mobile-builder/features.json`;
commit that folder. After removing or adding a feature that has native code, rebuild the development
client. The builder's `_expo/docs/FEATURES.md` lists exactly what each command changes.
