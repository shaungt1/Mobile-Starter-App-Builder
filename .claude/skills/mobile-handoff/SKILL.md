# Hand-off

Report, in this order:
1. The plan used (platform, name, bundle ID, frontend/UI kit for Tauri, capabilities).
2. Every command run and whether it passed.
3. Targets launched (web, Expo Go, Android emulator, USB phone, iOS Simulator, Tauri desktop) and targets not tested, with the reason.
4. Manual steps left for the user (Android Studio wizard, accounts, store dashboards, signing, environment values).
5. App path, Git branch, last commit, and whether it was pushed.
